# 🎮 Videogames and Platforms Potential

## 🧠 Descripción

Este proyecto tiene como finalidad **evaluar datos históricos de ventas de videojuegos** para identificar patrones en el mercado que permitan **detectar proyectos prometedores** y apoyar la **planificación estratégica de campañas publicitarias**.  
El análisis de tendencias en ventas y plataformas puede proporcionar información útil para desarrolladores, publishers y equipos de marketing en la industria del gaming. :contentReference[oaicite:1]{index=1}

Este trabajo fue desarrollado en el marco de mi formación como **Data Scientist en el bootcamp TripleTen**.

---

## 🎯 Objetivos

- Analizar un conjunto de datos históricos de ventas de videojuegos.
- Explorar la relación entre plataformas, géneros, años y ventas.
- Identificar patrones de éxito en el mercado de videojuegos.
- Proponer insights que puedan ayudar en la toma de decisiones de negocio.

## 📊 Metodología y análisis

Dentro del notebook se desarrollan:

1. **Carga y exploración de datos**
Revisión de valores nulos, tipos de datos y estadísticas básicas.

2. **Análisis exploratorio de datos (EDA)**
Gráficas y comparaciones entre ventas por región, plataforma, año y género.

3. **Identificación de patrones de potencial éxito**
Uso de métricas descriptivas para encontrar tendencias relevantes.

4. **Conclusiones y recomendaciones**
Insights clave basados en el comportamiento histórico de las ventas.
